# 第一次陪孩子使用：五分钟指南

目标：让孩子知道“游戏是我自己做的，小教练只给任务和提示”，并顺利完成第 1 关的第一个步骤。之后的 10–20 分钟，孩子可以按自己的节奏继续。

## 开始前（家长自己准备，约 1 分钟）

- 用电脑打开两个窗口：左边 Scratch（在线版 <https://scratch.mit.edu/projects/editor/>，或 Scratch 桌面版），右边双击打开本项目的 `index.html`。
- 把右边窗口拉窄，大约占屏幕三分之一。
- 默认界面是简单英语。如果孩子英语还不熟，点右上角“🌐 中文”切换，积木名称始终中英文对照。

## 五分钟流程

| 时间 | 做什么 | 家长可以说 |
|---|---|---|
| 0–1 分钟 | 摆好窗口，指给孩子看：左边是做游戏的地方，右边是小教练。 | “左边是你的工作台，右边是给你出任务的小教练。” |
| 1–2 分钟 | 说清规则：小教练看不到你的作品，测试要靠你自己；可以要提示，也可以跳过。 | “它不会给你打分，你自己测试，觉得做好了就点‘我试过了’。” |
| 2–3 分钟 | 点“Start Level 1 / 开始第 1 关”，一起读任务，回答“先预测一下”的问题，再点“看答案”。 | “你猜会发生什么？说出来，然后去 Scratch 里验证。” |
| 3–4 分钟 | 做第一步：把角色改名为 Hero。**鼠标交给孩子**，家长只提问不动手。卡住就点“给我一点提示”。 | “提示 1 说让你看哪里？你找到那个框了吗？” |
| 4–5 分钟 | 点“我试过了”进入下一步；约定本次时长（默认 20 分钟），结束前在 Scratch 里“文件 → 保存到你的电脑”。 | “做到 20 分钟左右我们就保存、休息一下。” |

## 之后陪伴的小原则

- **多问少教**：问“哪个角色负责这件事？”“你觉得这个数字是什么意思？”，不直接替他拖积木。
- **提示按顺序开**：先观察，再找积木分类，最后才看积木顺序。
- **出错很正常**：点“遇到问题”看常见原因，或者一起一次只检查一个角色。
- **不比较、不惩罚**：没有排行榜和签到。累了就停，下次点“继续学习”。
- **看演示比看勾选更可靠**：进度页的勾选是孩子自己点的；请他演示游戏、讲讲某个积木为什么放在那里，才是真正的检查。

## 隐私提醒

记录只保存在这台电脑的这个浏览器里，同一浏览器的其他人可能看到。需要时在“家长页 → 清除本地记录”删除。不要让孩子把真实姓名写进 Scratch 作品名或文件名。
