# Scratch 小教练 · 积木大冒险（Block Quest）

一个放在 **Scratch 编辑器旁边**使用的离线教学助手，帮助小学阶段的初学者一边用 Scratch 搭积木，一边学编程。

孩子在官方 Scratch（网页版或桌面版）里自己动手；在本应用里看任务、逐级获取提示、记录自查。8 个连续关卡最终做成一个完整可玩的 **2D 卡通闯关游戏**：方向键移动、岩浆陷阱、金币计分、检查点、终点胜利，再加上孩子自己的音效和规则。

- 不是 Scratch 编辑器，也不替孩子完成游戏。
- **看不到**孩子的 Scratch 项目，**不会**自动检查代码；“我试过了”和测试勾选都是孩子自己标记的。
- 不需要网络、登录或任何 AI 接口。只有打开在线 Scratch 本身需要网络，Scratch 桌面版可离线使用。
- 与 Scratch、MIT 媒体实验室及 Roblox 均无关联，不使用它们的品牌素材。

## 启动方法

1. 下载或克隆本项目，保持文件夹结构不变：
   ```
   scratch-coach/
   ├── index.html        ← 双击这个文件
   ├── css/styles.css
   ├── js/content.js     ← 8 关课程内容
   ├── js/storage.js     ← 本地进度存储
   ├── js/app.js         ← 界面逻辑
   ├── docs/             ← 家长五分钟指南、测试结果
   └── tests/            ← 自动化测试
   ```
2. **双击 `index.html`**，用 Chrome、Edge 或 Firefox 打开即可。不需要安装任何东西，也不需要联网。
3. 把浏览器窗口拉窄（约 360–480 像素宽）放在屏幕一侧，另一侧打开 Scratch：
   - 在线版：<https://scratch.mit.edu/projects/editor/>（需要网络）
   - 桌面版：Scratch 官方桌面应用（可离线使用）

> 可选：如果浏览器对本地文件限制较严，也可以在项目目录运行 `python3 -m http.server 8000`，再打开 `http://localhost:8000/`。注意：换了打开方式后，浏览器会把它当作另一个网站，之前的进度不会带过来。

## 使用方法

### 孩子（默认简单英语，右上角可切换中文）

1. 首页有**冒险地图**（8 关路线图）和**继续学习**按钮。
2. 每关的页面顺序：开始（任务 + 先预测）→ 步骤 1–3 → 测试 → 加分挑战与回顾。每屏只聚焦一个小步骤。
3. 每个步骤有三个按钮：
   - **✅ 我试过了**：在 Scratch 里做完后点它，进入下一步。
   - **💡 给我一点提示**：逐级展开。提示 1 引导观察，提示 2 指出积木分类，提示 3 才给出**当前步骤**的小段积木顺序。
   - **🛠 遇到问题**：列出本关常见问题和针对性建议。
4. 可以随时**返回**、**跳过这一步**、点上方的步骤标签跳转，或在最后一页**重做这一关**（会先确认）。
5. 积木名称始终**中英文对照**显示，并标注所属分类（事件 / 运动 / 外观 / 声音 / 控制 / 侦测 / 运算 / 变量）。

### 家长（中文页面，右上角“家长 Parents”）

- 如何陪伴、第一次使用的五分钟指南。
- 查看孩子**自行标记**的进度：每关标记“试过了”的步骤数、看到的最高提示级别、测试勾选、挑战、感受。这只是自查记录，**不是客观能力评估**。
- 设置孩子界面语言（English / 简体中文）和建议学习时长（15 / 20 / 25 / 30 分钟或不提醒）。到时间只会温和提醒“保存作品、休息一下”，不锁定、不惩罚。
- 清除本地记录（需要二次确认）。
- 课程概览、每关陪伴要点，以及完成后游戏的**完整参考脚本**（默认折叠，建议先让孩子用逐级提示）。

第一次陪孩子使用，请看 [docs/家长五分钟指南.md](docs/家长五分钟指南.md)。

## 课程概览

| 关卡 | 名称 | 核心概念 | 本关做出的东西 |
|---|---|---|---|
| 1 | 出生岛 Spawn Island | 事件、绿旗 | 主角 Hero、关卡背景、起点；绿旗把 Hero 送回 (-200, -130) |
| 2 | 方向键冲刺 Arrow Run | 循环、坐标 | “重复执行”+“如果按下方向键”控制四向移动 |
| 3 | 岩浆陷阱 Lava Trap | 条件、碰撞检测 | Lava 角色；Hero 碰到就回起点 |
| 4 | 金币收集 Coin Collector | 变量 | Score 变量（绿旗归零）；金币用“等待碰到 Hero”只算一次 |
| 5 | 检查点旗帜 Checkpoint Flag | 用变量记住位置 | Checkpoint X/Y（绿旗设回起点）；岩浆送回检查点 |
| 6 | 胜利传送门 Victory Portal | 广播 | Goal 只广播一次 You Win；横幅显示；Hero 停止移动 |
| 7 | 打造你的风格 Make It Yours | 音效、造型、自定义规则 | 音效、造型、自选规则（如 3 条命） |
| 8 | 测试员与存档点 Tester & Save Point | 测试、调试、保存 | 测试清单、讲解一个概念、保存并重新打开 .sb3 |

每关都包含：孩子能懂的目标、2–3 个小步骤、预测问题、每步三级提示、实际运行检查、至少两个常见问题、可选挑战和简短反思。

### 课程中特别保证一致的地方

- **起点统一**：第 1 关的起点、第 3 关岩浆复位、第 5 关检查点初始值都是 x: -200, y: -130。
- **绿旗重置**：Score 归零、检查点设回起点、金币重新显示、胜利横幅隐藏，都放在绿旗脚本里。
- **金币不重复加分**：金币脚本是“显示 → 移到位置 → 等待 0.2 秒 → 等待碰到 Hero → Score 加 1 → 隐藏”，没有“重复执行”。
- **检查点**：放在 Checkpoint 角色上，用它自己的“x 坐标 / y 坐标”。
- **胜利只触发一次**：终点用“等待碰到 Hero”后广播一次；Hero 收到后“停止该角色的其他脚本”。
- **短暂等待 0.2 秒**：金币、检查点、终点开局先等 0.2 秒，让 Hero 先回到起点，避免上局停在终点或金币上时开局被误触发。
- 这些规则都由自动化测试检查（见下方）。

## 隐私说明

- **完全本地**：不加载远程字体、CDN、外部图片或分析工具；页面设置了禁止网络请求的安全策略。只有点击“打开在线 Scratch”链接时，浏览器才会访问 Scratch 官网。
- **不收集个人信息**：不要求、不保存孩子的姓名、生日、学校、照片或声音。没有账号、上传、公开分享、摄像头、麦克风或实时 AI。反思环节只让孩子讲给大人听或点表情，不提供自由输入框。
- **只保存在本浏览器的 localStorage**：界面语言、建议时长、每关步骤标记、提示级别、测试勾选、挑战标记和感受。
- **同一台电脑、同一个浏览器的其他使用者可能看到这些记录**。可在家长页“清除本地记录”，或在浏览器设置里清除本站数据。
- 存储不可用（如隐私模式、禁用网站数据）或数据损坏时，页面不会白屏，会在顶部提示“进度可能无法保存”或“进度已损坏并重置”，课程照常可用。

## 故障处理

| 现象 | 原因与处理 |
|---|---|
| 双击后页面空白 | 确认 `css/`、`js/` 文件夹和 `index.html` 在同一目录；确认浏览器开启了 JavaScript；换用最新版 Chrome / Edge / Firefox。 |
| 顶部提示“无法保存进度” | 浏览器处于无痕/隐私模式或禁用了网站数据。课程可正常使用，但关闭页面后勾选会丢失。换普通窗口或允许本地数据即可。 |
| 顶部提示“最新进度没能保存” | 浏览器存储空间满或被阻止。清理浏览器数据后重试。 |
| 顶部提示“保存的进度损坏了” | 记录已自动重置，可直接在地图上选关继续。 |
| 进度“消失”了 | 进度按浏览器和打开方式分别保存：换了浏览器、用了隐私窗口、或从双击改成 `http://localhost` 打开，都会看到一份新的记录。 |
| 在线 Scratch 打不开 | 在线版需要网络。没有网络时请使用 Scratch 桌面版，本应用本身可完全离线使用。 |
| 找不到 .sb3 文件 | 在线版通常下载到“下载”文件夹（可能叫 `Scratch Project (1).sb3`）；桌面版会询问保存位置。 |
| 想重新开始 | 家长页 →“清除本地记录”，或在某一关最后一页点“重做这一关”。 |

## 运行测试

需要 Node.js 18 或更高版本（测试使用内置的 `node:test`，无需安装依赖）。

```bash
npm test
```

上面的命令运行课程一致性测试和存储测试。浏览器测试需要 Playwright 和 Chromium：

```bash
npm install --no-save playwright && npx playwright install chromium
```

```bash
npm run test:browser
```

没有安装 Playwright 时，浏览器测试会自动标记为跳过，不会报错。设置环境变量 `SHOT_DIR=某个文件夹` 可以保存窄窗口截图。

最近一次测试结果见 [docs/测试结果.md](docs/测试结果.md)。

## 修改课程

全部课程内容在 `js/content.js` 里，是普通的数据结构（中英文成对）。修改后请运行 `npm test`：测试会检查每关结构是否完整、积木是否为真实的 Scratch 3 积木、角色/变量/消息名称是否一致，以及绿旗重置、金币只算一次、检查点复位、胜利只触发一次等逻辑。
